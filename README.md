# MODT (Modeling Tool)

MODT is a high-level modeling language and CLI utility designed to automate the software design process. It captures system structures, behaviors, and relationships through a simple, human-readable syntax.

### Key Capabilities

- **Diagram Generation**: Automated PlantUML diagrams (Class, Domain, Activity, Sequence, State).
- **Database Schemas**: Intelligent SQL DDL generation with type mapping.
- **Documentation**: Professional Markdown and PDF manual generation.
- **Multi-phase Support**: Distinct handling for Analysis and Design models.

For more details, see [Documentation.md](Documentation.md).
