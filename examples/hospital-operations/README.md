# Hospital Operations

A healthcare operations example that models:

- patient, clinician, and nursing roles with inheritance
- appointment scheduling and consultation flow
- encounter notes, prescriptions, lab orders, and insurance
- use cases that drive activity, sequence, and state diagrams
- analysis- and design-oriented attributes in the same project

Run from the repository root:

```bash
./modt --input examples/hospital-operations
```

Generated files land in `examples/hospital-operations/generated/` and are checked into the repository as an example snapshot.
